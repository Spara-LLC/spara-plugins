# Publish a close

Select the client and the closed month. Read `kb/sharepoint.md` and the files under `closes/YYYY-MM/` with `get_client_context`. List the close notes that are ready.

This plugin cannot upload to SharePoint. Do not ask for Microsoft credentials and do not claim the files were published. Tell the user the SharePoint delivery still runs from Spara OS after they approve it there.
