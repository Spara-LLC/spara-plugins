# Cash forecast

Do not invent forecast numbers and do not edit an Excel workbook. Say this update is not available in the ChatGPT plugin yet.

If the user wants current cash, select the client, confirm the company, and read the bank balances from QuickBooks with `search_qbo_records` on `account` or the balance sheet. Label those figures as book balances, not as the forecast.
