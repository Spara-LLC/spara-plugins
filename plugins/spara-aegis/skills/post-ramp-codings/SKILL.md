# Ramp card spend

Aegis does not code Ramp. Do not create a QuickBooks purchase for a Ramp card charge, Ramp bill payment, or Ramp reimbursement.

Read `kb/coding-rules.md` and `kb/accounting-finance-map.md` to recognize those lines. List them as skipped, with the statement date, description, and amount. Tell the user Ramp coding still happens in Ramp, and Ramp's own sync posts QuickBooks.
